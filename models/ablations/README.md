# 原始 CSG 五组消融

每个 `.py` 都是独立上传文件，仅依赖 PyTorch，导出 MODEL_SPEC 和 build_model(config)。平台负责数据加载、训练、早停、指标和 checkpoint。

| 组 | 文件 | forward 接口 | 信息来源 | 参数量（5 通道、20→20、默认超参） |
|---|---|---|---|---:|
| ① | 01_baseline.py | forward(x) | 原 ConvLSTM-SimVP，无门控 | 157,441 |
| ② | 02_dynamic.py | forward(x) | 动态特征 E 生成门控 | 159,554 |
| ③ | 03_dynamic_ls.py | forward(x, ls) | E + Ls | 534,562 |
| ④ | 04_dynamic_topography.py | forward(x, topography) | E + MOLA | 542,914 |
| ⑤ | 05_full.py | forward(x, ls, topography) | E + Ls + MOLA | 544,130 |

## 默认配置（2026-09-22 更新）

按要求，从③开始使用新默认值；①②的文件默认值保持原样。

| 参数 | ①②默认值 | ③④⑤默认值 |
|---|---:|---:|
| convlstm_hidden_dim | 16 | 16 |
| spatial_hidden_dim | 32 | 64 |
| temporal_hidden_dim | 64 | 128 |
| num_temporal_blocks | 3 | 2 |
| dropout | 0.1 | 0.1 |
| gate_hidden_dim | ②为32；①无 | 32 |
| initial_gate_strength | ②为1；①无 | 1 |

进行五组消融比较时，实际训练配置仍须统一：若①②已经在平台手动设置为 16/64/128/2，则与③—⑤的新默认主干一致；若①②按旧默认训练，则需用统一配置重跑才能用于严格的条件消融比较。上述参数量按各文件当前默认配置统计，因此①②与③—⑤不是同一主干容量。

## 门强度的准确含义

②—⑤的 `initial_gate_strength` 默认值均为 1.0，s 仍是可学习参数，沿用原始 CSG 的直通截断，前向有效值在 [0,1]。这不是“训练全程固定 s=1”的版本。①没有门强度参数。

保持原始 CSG 的 tanh 和输出投影 Xavier gain=0.01；未添加加性残差、直接融合或逐层 FiLM。地形输入在进入卷积前转换为权重 dtype。

## 控制变量

- 未启用的条件编码器从模型中移除，避免零输入经过带偏置编码器后仍产生贡献。
- ②—⑤先按原顺序构造分支，再删除未启用分支，在相同结构超参数及同一 seed 下保证公共参数初始化一致。各组参数量仍不同，不能据此声称已控制容量。
- ①是原主干的独立副本，初始化顺序与门控组不同。若需要五组公共主干初始权重完全相同，应在训练平台显式复制同一份主干初始权重；同 seed 本身不能保证这一点。
- 所有组保持相同数据划分、归一化、训练预算、损失、优化器及 checkpoint 选择规则；每组从头训练，使用相同的至少三个随机种子。
- 建议将验证 RMSE 作为预先确定的主要指标，并报告 MAE、逐步误差、均值与标准差；记录实际最终门强度。
- 在平台分别上传五个文件。③只声明 Ls，④只声明 MOLA，⑤声明两者，①②不需要辅助输入。

## 验证

对应测试：`tests/test_csg_ablations.py`。
覆盖全部五组的 20→20、多通道、奇数空间尺寸、完整反向传播、分支移除、相同种子的公共权重一致性、⑤与原始 CSG 的输出等价性，以及门强度归零后与共享权重基线的严格等价性。

这些测试确认实现性质，不代表已完成实际数据训练或验证预测增益。
